# 粒子、拖尾与模型

## 从制作到控制

在 Unity 使用原生 ParticleSystem、TrailRenderer、网格和受支持的模型动画制作。导出后，在游戏侧实例化根模板，取得 RimUnity 组件进行播放、停止和变换。业务对象负责效果的持有和销毁。

停止发射与销毁对象是两件事。需要保留收尾时先 Stop，完成后再销毁实例；不要把共享模板作为活动效果使用。

## 可以使用哪些粒子功能

当前支持多种发射、形状、曲线、渐变、外力、噪声、子发射器、纹理图集、拖尾和网格粒子功能。部分 2D/3D 碰撞、Trigger、简单刚体和 Point Lights 已接通。完整模块列表及参数边界保留在原文“粒子模块与使用限制”。

这些模拟不会自动把 RimWorld 的墙、地面和 Pawn 变成 Collider。Lights 影响地图格子照明，不等于三维逐像素灯光。物理不等同完整 PhysX/Box2D，也不支持原生粒子 Jobs 或 GPU Instancing。

## 渲染与动画的检查顺序

1. 核对实际运行的 Prefab 名称，避免诊断窗口采到了另一个特效。
2. 核对根与子节点的变换、粒子朝向、缩放和 Layer。
3. 检查实际材质、纹理通道、UV 和 Shader 变体。
4. 检查材质队列、深度和模板测试；Layer 编号不是 RimWorld 的高度层。
5. 需要 Bloom 时为相关子节点设置参与的 Layer。

部分随机轨迹、缩放、图集混合和 Renderer 参数与 Unity 有差异。Animator 不支持完整 Humanoid、IK 和复杂过渡中断；不要按完整 Unity 兼容层理解。
