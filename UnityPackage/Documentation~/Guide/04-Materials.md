# 材质、贴图与自定义 Shader

## 先判断是哪条导出路径

已支持的内置 Unlit 和标准粒子材质由导出器映射。自定义 Shader 需要配置目标 RimWorld 安装目录与离线 ShaderTool。转换后的 GLSL、状态描述和依赖随内容模组发布。

导出前处理应在 Shader 转换前完成，使属性、关键字、状态和纹理依赖保持一致。只改最终 JSON 可能让程序变体与材质数值不匹配。

## 颜色贴图与数值贴图

颜色贴图按实际用途设置 sRGB；噪声、遮罩和动画数据通常使用 Linear。不要把所有贴图一律改成同一种编码。

浮点纹理以四通道浮点载荷保存，保留负数和 HDR 值。网格支持最多八个四维 UV 通道，可用于顶点动画。非可读纹理的读回需要真实图形设备，Null 图形设备下不会假装成功。

## 常见导出边界

导出器支持指定范围的属性、关键字、采样、混合、剔除、深度、模板和顶点变换。对不支持的程序或状态会给出错误，部分数学或深度近似会记录说明。软粒子的地表深度近似不包含建筑和角色。

Shader Graph 与完整 Unity 后处理栈不在支持范围内。Surface、ShadowCaster、离屏 Camera、方向光和多 Pass 的具体限制请查原文“自定义 Shader 导出”，不要把“可导出”理解成与 Unity 逐像素一致。

## 修改游戏侧材质

加载器返回的材质和纹理是共享资源。实例差异优先用 MaterialPropertyBlock，或创建并负责销毁独立材质。更换编码不同的纹理时，PropertyBlock 需要同步对应的 _RimUnitySrgb 属性；普通 Material.SetTexture 会进行相应同步。
