# UI 与 IMGUI 材质

## 预制体界面

在 Unity 中使用 UGUI 制作层级与布局。游戏侧使用 RimUnity.UI 和 RimUnity.EventSystems；自定义脚本需要对应游戏侧实现，不能只把作者脚本导出后就期待它运行。

支持范围包含指定的 Canvas、图片、Text、基础 TMP、按钮、滚动、遮罩和输入交互。Simple/Sliced 图片遮罩、RectMask2D 羽化以及部分文字字重、字距、Shadow 和 Outline 已接通。TMP 不提供完整动态字形和复杂排版。

UI 资源需要使用对应导出模式。屏幕 UI 材质与地图材质的顶点布局不同；运行时才挂到相机画布的独立预制体应使用相机 UI 设置。

## IMGUI 自定义材质

把需要直接加载的材质作为独立入口导出，指定稳定逻辑路径。游戏侧通过 AssetLoader 加载并按文档桥接到宿主绘制 API。材质输入、遮罩与透明度应使用该路径支持的形式。

完整代码见原文“IMGUI 自定义材质”。不要把地图 Bloom 的行为直接套到 UI，普通 UI 和世界地图不参与地图 Bloom 通道。

## 常见交互问题

先检查 Canvas 模式、层级活动状态、事件目标和游戏侧脚本类型。字段应指向当前实例的组件；不要订阅模板上的控件。窗口关闭或实例禁用时解除事件订阅。

AudioSource 当前主要用于无 Mixer 路由的二维界面音频；补间只覆盖已经接通的属性，不等同完整 DOTween。
