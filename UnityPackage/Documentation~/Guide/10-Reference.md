# 支持范围、原文与维护

## 如何使用这本手册

说明书区按制作任务整理，适合快速找到下一步。原文区保留仓库根目录和 UnityPackage 的中英文 README、Steam 简介说明、1.6 占位说明，以及 Docs 下的专题文档。

搜索检查标题、来源路径和全文。可以按“说明书”“原文·中文”“原文·English”“其他原文”筛选；每页可复制全文或打开对应文件。正文中的文档链接可以跳转到已收录的原文，外部网页链接交给浏览器打开。

## 原文与概述的关系

概述不会替代详细 API、参数边界和许可证。遇到具体支持问题，请阅读对应原文并结合当前导出错误确认。示例资源名、逻辑路径与 Layer 都需要替换成项目实际值。

所有功能面向 RimWorld 1.7。1.6 README 作为历史说明保留，不代表提供 1.6 运行时。

## 更新离线文档

仓库维护者修改 README 或 Docs 后执行 Tools/Sync-Manual.ps1，更新随包分发的原文快照和索引。Tools/Pack.ps1 会在打包时同步；带 -Check 参数只核对，不写文件。

修改或新增说明书章节放在 UnityPackage/Documentation~/Guide。这里按文件名前缀确定顺序，不需要改窗口代码。Documentation~ 随 UPM 包发布，但不会作为项目美术资源导入。

## 许可和资源交付

RimUnity 使用 MIT 许可证，第三方声明见仓库 ThirdParty/NOTICE.md。内容模组的美术、字体及其他资产仍按其自身许可分发；框架许可不会替代素材许可。

Steam README 介绍图文简介的维护，性能图解释机制，不代表实测 FPS 或固定加速倍率。发布承诺应以实际游戏验证为准。
