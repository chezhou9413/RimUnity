# 颜色与 Bloom 怎么配

## 先把材质颜色配正确

导出器读取 Unity 的 Gamma/Linear 配置，保留材质颜色、透明度、混合与绘制状态。Linear 工程的地图材质使用线性 HDR 混合，关闭 Bloom 不会关闭线性混合。

高于 1 的亮度可以参与叠加和 Bloom，但最终屏幕仍有亮度上限。没有完整曝光和色调映射时，不能保证与启用了这些效果的 Unity 相机一致。

## 开启 Bloom 的步骤

1. 在 Unity 给特效对象及相关子节点设置专用 Layer。
2. 正常导出，进入游戏地图。
3. 选项 → 模组设置 → RimUnity，开启 Bloom 并选择对应 Layer。
4. 调整阈值、强度、柔和度和扩散，观察多个特效叠加后的效果。

默认关闭且未选层。普通地表通常在 0 层，不建议直接勾选它；过高强度容易使画面发白。Layer 按编号匹配，根节点改层不会自动改变子节点。

## 内容模组接管开关

游戏主线程调用 Bloom.SetLayerEnabled(layer, enabled)，并在结束时 ReleaseLayer(layer)。同一层应由一个模组负责，读档或新游戏时由内容模组同步自己的保存值。

## 支持边界

地图粒子、拖尾和模型可参与；普通 UI、世界地图不在这一范围。显式宿主 Pawn 预览可以使用 BloomPreview 会话，并按文档在 finally 中结束、窗口关闭时 Dispose。

Bloom 仍遵守深度与材质状态。它不会自动修复资源遮挡、纹理通道或 Shader 错误。HDR 缓冲和颜色空间切换也有开销，实际成本需要在目标画面中测量。
