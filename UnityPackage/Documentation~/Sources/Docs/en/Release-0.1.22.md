# 0.1.22 Release Notes

- Support RimWorld 1.7.4998.
- Add automatic CPU comparisons between legacy and current trail writing within the same particle lab process, reporting geometry generation, submission and batch flushing costs.
- Fix the measurement panel sometimes remaining invisible and restore a visible position when entering the lab.
- Add finer trail, batching and mesh upload sampling in particle analysis builds to help locate processing costs.

Content mods using the embedded runtime should update their embedded package.
