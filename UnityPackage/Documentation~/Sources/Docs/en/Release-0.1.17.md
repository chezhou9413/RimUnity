# 0.1.17 Release Notes

- Optimize particle simulation, attribute evaluation and mesh generation to reduce CPU overhead in dense effects.
- Fix mesh particle alignment, custom animation channels and emission timing; keep particle playback independent of game speed.
- Improve particle performance diagnostics for simulation and rendering costs.
- Fix a null-reference error before the new-game interface is ready.

Content mods using the embedded runtime should update their embedded package.
