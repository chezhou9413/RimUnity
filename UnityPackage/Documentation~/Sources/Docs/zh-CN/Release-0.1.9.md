# 0.1.9 Preview · 验证范围

2026-10-16，基于 RimWorld 1.7.4980 rev60、.NET 10。keeptpa 的粒子随机种子、LoadFolders 条件目录修复及发布界面增强先通过 PR #4 合入主干，构建路径修复保留。

## 本版内容

- 正常构建同时生成独立运行时和内置容器，包含 Core、主运行时、Spine、全部内置 Defs/GLSL、双语设置文字及许可。
- 纯资源模组可携带内置 DLL；C# 模组使用 targets 发布延迟脚本和版本声明。编译引用单独放在 References，不能分发为额外运行时。
- 独立前置优先；相同内置副本只运行一次；选择最新兼容载荷；同版本不同载荷报错。
- Unity Inspector 风格的渲染、运行时、关于我们设置页，中文/英文与英文回退，保留 Bloom 设置键和 API。
- 关于页包含 GitHub、创意工坊、贡献者、参与邀请、MIT 与第三方许可，并明确不包含真实 Unity 引擎。
- 无联网检测、自动下载更新或新增 Unity 导出选项。

## 已完成

运行时、Core、Spine、Embedded、ShaderTool、Unity 导出工具源码编译通过。已有 PublishingTests、CatalogPolicyTests 通过。保留第三方 Spine 的 3 个 CA2022 警告和导出工具的 5 个旧粒子枚举弃用警告。

`Tools/Verify-Embedded.ps1` 使用真实 CLR、发行版 DLL、游戏的 Mod 创建工厂和 Harmony XML 入口。覆盖单副本、相同副本、顺序交换、独立前置在前/中/后、MonoBehaviour 派生、跨程序集继承、内容实例归属、重复进入保护、不兼容独立版、最新兼容候选和同版本载荷冲突。原生挂载、图形初始化和类型全集在离线宿主中隔离，因此这组检查本身不代表游戏内验证。

## 大型列表开销与未覆盖范围

新增目录扫描仅针对原版已登记了内置入口的模组；不遍历其他模组文件夹，也不扫描未启用模组。相同载荷常驻字节只保留一份。独立前置模式不读取或释放内置载荷。没有内容脚本时跳过额外内容 Mod 创建；独立模式也跳过已完成的运行时 Mod 创建。

离线样本中，2 个内置模组的完整引导阶段约 121 ms；加入 5,000 个无关模组登记项后约 144 ms。包含 JIT、文件读取、缓存释放和离线 Mod 创建，不是纯目录扫描时间，也不是游戏总启动时间。没有为规模检查启动几千模组的游戏。真实列表的程序集类型数、磁盘速度、实际内置副本数会影响开销，尤其是游戏类型缓存刷新。

尚未覆盖地图中的长期渲染、所有资源类型组合、设置窗口在所有语言/缩放下的目视检查。设置布局做了实际文本高度和 GUI 状态恢复的静态核对。请将本版视为预发布，而非完整游戏回归认证。
