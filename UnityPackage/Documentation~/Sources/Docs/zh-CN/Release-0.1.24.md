# 0.1.24 更新说明

- 修复 RimWorld 1.7.5011 更新后，屏幕特效清理资源时因后处理接口变化而崩溃，并在启动时检查接口兼容性。
- Bloom 和地图 HDR 在渲染目标重建时保留已预热的网格渲染器，只在 GPU 空闲后释放附件并按新尺寸重建。
- 适配新版 UI 绘制记录，修复自定义 UI 材质的提交。
- 调整 Shader 转换诊断，已处理的整数幂兼容与屏幕 UI 颜色混合说明改为普通日志，阴影 Pass 不再报告颜色混合差异。
- 增加只依赖 .NET 10 SDK 的跨平台构建、文档同步和打包入口，自动发现 Steam 游戏与 Harmony，支持本地路径配置。

使用内置运行时的内容模组需同步更新内置包。源码构建入口为 Windows 的 `build.cmd` 或 Linux/macOS 的 `sh build.sh`，不再要求 PowerShell。
