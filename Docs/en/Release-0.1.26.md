# 0.1.26 Release Notes

- Fixed text entry in affected mod windows on RimWorld 1.7.5014. Chinese input method candidates now appear at the caret, and shortcuts such as Esc respond again.
- Improved mouse input for dropdowns and scrollbars. Fixed misplaced pop-ups on first open and text turning into black blocks in windows with several scrolling lists.
- Mods can now add custom screen effects. Frames without bloom or screen effects take less work to render.
