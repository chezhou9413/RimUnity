# 0.1.20 Release Notes

- Optimize particle simulation dispatch and trail vertex writes.
- Improve performance metrics and add a native panel for automated measurements and quick rechecks.
- Preserve prefab Canvas pivots to fix shifted local coordinates.
- Fix repeated parent hover events when moving between child controls, and single-line text disappearing due to line height or scaling.
- Allow dragging the RimUnity settings window by its title or empty areas.

Content mods using the embedded runtime should update their embedded package.
